# Changelog

## Unreleased

- S11: bookmarks. Bookmark a step from its title row, an answer from its menu, or code with **LogicLens: Add Bookmark** (`Ctrl+Alt+E M`), with an optional note. The new LogicLens activity bar view lists them by file; selecting one highlights its lines and shows the saved explanation, with **Explain Again**. Bookmarks keep a copy of their text, survive Clear Cache, move with edits, and show "code changed" when their lines are gone. Possible secrets are stored only as hashes.
- S10: **LogicLens: Follow to Definition** (`Ctrl+Alt+E G`, editor context menu, or **Follow…** on a step) opens a definition and records a trail. Breadcrumbs above line 1 show where you came from; click one, or use **Trail Back** / **Trail Forward** (`Ctrl+Alt+E [` / `]`), to return to the exact spot and step. Landing in a file without a walkthrough offers **Explain <symbol>**. Following never sends code. **Clear Trail** empties it; the trail survives a window reload.
- S8: walkthroughs and question threads are cached in VS Code's extension storage (never the workspace) and come back when you reopen a file, labelled "Generated <time> ago". Steps and threads move with edits; edited steps show "(code changed)", and **Refresh Changed Steps** rewrites only those, while **Refresh** regenerates everything. After outside changes, steps are found again by their original text. New setting `logiclens.cache.enabled` and command **LogicLens: Clear Cache**. Lines withheld as possible secrets are stored only as hashes.
- S3: explain a selection (**Explain Selection**, `Ctrl+Alt+E S`), a symbol (**Explain Symbol**, or the opt-in "Explain" CodeLens with `logiclens.codeLens.enabled`), or a file from the Explorer or editor context menu. Files over the line limit offer the selection, visible range, or a symbol. New settings `logiclens.depth`, `logiclens.audience` (including "Explain like I'm five"), `logiclens.jargon`, and `logiclens.explanationLanguage`; change them from **Adjust Explanation…** on the explanation and regenerate. Answers follow the audience, jargon, and language.
- S6: Claude Code is a provider. LogicLens runs `claude` headless with its tools, MCP servers, and settings turned off, in an empty folder outside your workspace, with the prompt on stdin. Pick it from the status bar; choose its default model or Sonnet, Opus, or Haiku. New settings `logiclens.cli.claudePath` (machine scope) and `logiclens.cli.timeoutSeconds`. Stop kills the CLI. Token counts appear in the walkthrough header when the provider reports them.
- S5: the status bar shows the AI model LogicLens uses; click it (or **LogicLens: Select AI Provider** / **Select Model**) to switch. New settings `logiclens.provider` and `logiclens.model`. With several providers ready, LogicLens asks on first use; when none is ready the status bar warns and requests offer **Choose Provider**. LogicLens never switches provider on its own. **Regenerate with…** on the explanation re-runs it once with another model. **LogicLens: Reset Data Notices** shows each provider's data notice again.
- S4: ask a question at any line. **LogicLens: Ask About This Line** (editor context menu, `Ctrl+Alt+E Q`, or the gutter "+" once LogicLens is active) opens an inline thread; the answer streams under the line with Stop, and each answer can be copied, regenerated, or deleted. Follow-ups use the earlier turns. Step threads have **Ask About This Step**, and concept tags ask about the concept with the question pre-filled. Line references in answers are links. Threads move with edits and show "Code changed" when their lines are deleted. **Clear Threads in File** and **Clear All Threads** remove them.
- S2: **LogicLens: Explain File** now produces a step-by-step walkthrough. The overview and summary sit at the top of the file; each step's explanation sits just above the code it explains, with a title row (number, title, lines, Previous, Next). Alt+] and Alt+[ move between steps, which highlights the step, dims the rest, shows its number in the gutter, and opens its explanation; Escape clears the highlight. **Show All Steps** expands every step. A response that ends early offers **Continue**. New settings `logiclens.focusDimming` and `logiclens.followCursor`. `pnpm eval` measures recorded responses against a 10-file seed corpus.
- Scope: the MVP targets VS Code stable on Linux only and publishes to the VS Code Marketplace only (ADR-0026, supersedes ADR-0012). Windows and macOS move to new slice S13; Open VSX and VS Code forks to S7.
- S1: **LogicLens: Explain File** streams a plain-Markdown explanation of the active file from VS Code language models (for example GitHub Copilot) inline in the editor, as a block at the top of the file over the code (ADR-0028), with Stop, Explain again, and **LogicLens: Close Explanation** in its title, a provider and model header, and **LogicLens: View Terms of Use**. There is no side panel; model output is rendered by VS Code with HTML and command links off and images shown as links.
- S1: every request goes through the request gate: terms of use, workspace trust, `logiclens.exclude` plus `.logiclensignore`, size limit, one-time data notice, and a local secret scan that withholds flagged lines (lock icon in the gutter, notice in the explanation) or refuses under `logiclens.secrets.action: refuse-file`.
- S1: removed the S0 placeholder `LogicLens: Hello` command.
- S1: with Copilot, LogicLens now defaults to Copilot's chat model with the largest input window instead of the first model VS Code lists (which can be an agent-backed model).
- S0: feasibility spike complete for Copilot Free and Claude Code; the line-tagged protocol (ADR-0007) and the `^1.90.0` engine floor (ADR-0017) are accepted.
- Renamed the product from Clarity to LogicLens; identifiers now use the `logiclens.` prefix (ADR-0018).
- Added `TERMS.md` and the terms-of-use acceptance gate to the spec and plan (ADR-0024); the gate ships in S1.
- S0: repository skeleton, build, tests, CI, and a placeholder `LogicLens: Hello` command.
- Narrowed MVP providers to GitHub Copilot Free (through `vscode.lm`) and Claude Code; Codex, Gemini CLI, Kiro, API keys, Ollama, and fork checks moved to S7, after S12 (ADR-0025).
